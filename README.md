# 🐍 Python Data Analytics Assignment 1 – NumPy and Pandas

## 📌 Assignment Overview

This assignment focuses on performing basic data analysis using **NumPy** and **Pandas** in Python.

The assignment covers numerical computations using NumPy arrays and data manipulation and analysis using Pandas Series and DataFrames.

## 🎯 Objectives

* Work with NumPy arrays for numerical computations
* Perform array indexing and slicing
* Convert temperature values from Celsius to Fahrenheit
* Calculate maximum, minimum, and mean values
* Create and manipulate Pandas Series
* Perform indexing using `loc` and `iloc`
* Apply Boolean filtering
* Create and manipulate Pandas DataFrames
* Explore and analyze transaction data
* Perform grouping and aggregation using Pandas
